1. Actor & Presentation Layer

  • Citizens / Heads: Self-service registration, family tree visualization (React Flow), document upload, scheme discovery.
  • Officers & Admins: Multi-tiered review queues, side-by-side document scrutiny, deduplication resolution, GIS metrics.
  • Tech: React 18, TypeScript, Tailwind CSS, React Flow, Axios, Vite.

2. Backend Micro-Modules & Core Engines

  • Gateway: Node.js, Express, TypeScript, JWT auth, RBAC authorization, IP rate limit.
  • Family Identity Engine: Household graph relations, lifecycle states, head reassignment, state standard IDs.
  • Deduplication Pipeline: Multi-pass matching (Exact + Levenshtein / Soundex), BullMQ queue, confidence score clusters.

3. Persistence, Storage & Zero-PII ID

  • Relational DB: PostgreSQL/MySQL storing relations, family hierarchies, verification states, and immutable audit trails.
  • Storage & Cache: S3-compatible Object Storage for scanned documents; Redis for session cache and queue processing.
  • Identity Gateway: Tokenized references; strict zero-raw-PII storage policy.

4. Welfare Scheme Integration & Security

  • Schemes: Ration (NFSA), Housing (PMAY), Scholarships, Health (PM-JAY), Pensions, and PM-KISAN DBT hooks.
  • Security: End-to-end TLS 1.3, AES-256 at rest, pre-signed expiring S3 URLs, append-only immutable audit trail.
  • Analytics: SQL aggregate views, Chart.js KPI telemetry, district/taluka SLA heatmaps.
